# Laurel

*実績は勝ち取るもの、もらうものではない。*

**他の言語：** [Español](../LEEME.md) · [English](README.en.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md)

ゲームを準備して、**プレイ中に実績を獲得したときに Hydra Launcher が記録できるようにします**。
このアプリが自分で実績を解除することはありません。

## 使い方
1. `App\Laurel.exe` を開き、**言語を選択**します。スペイン語、英語、ポルトガル語、フランス語、ドイツ語、ロシア語、中国語、日本語の 8 言語に対応しています。「次回の起動時から表示しない」にチェックを入れた場合は、後で **言語** ボタンから変更できます。
2. 初回起動時、アプリは Hydra のダウンロードフォルダーを自動で探します（Hydra のデータは読み取るだけで、変更しません）。ゲームが別の場所にある場合は **追加…** を押してください。
3. **Steam API キー**を入力します。キーは無料で、「キーを取得」リンクから入手できます。キーがなくてもゲームのスキャンはできますが、準備はできません。**キーは一切保存されません。**メモリ上にのみ保持されるため、アプリを開くたびに入力が必要です。
4. **修復可能なゲームを準備** を押します。
5. アプリを開いたままにするか、最小化します（時計の横に常駐します）。ゲームをインストールすると、インストールの完了を待って自動で準備します。

**ヒント：**リスト上のカラーカードは状態ごとのゲーム数です。クリックするとそのゲームだけを表示します。検索ボックスでは名前・エミュレーター・AppID で絞り込めます。

## 各状態の意味
| 状態 | 意味 |
|---|---|
| OK | Hydra はすでにそのゲームの実績ファイルを見つけています |
| 準備完了 | 設定済みです。最初の実績を獲得するとファイルが作成されます |
| STEAM | `steam_api.dll` は Valve の正規品です（署名確認済み）。Hydra は Steam アカウントから実績を読み取ります |
| 修復可能 | Goldberg を使用していますが実績リストがありません。アプリが作成できます |
| APPID なし | ゲームを右クリック →「AppID を設定」 |
| 非対応 | DLL は Valve 製ではなく、既知のエミュレーターの特徴もありません。そのエミュレーターは Hydra が探す場所に実績を保存しません |
| STEAM なし | Steam を使用していません。アプリは使用しているプラットフォームを表示します：GOG（実績あり／なし）、Epic、Ubisoft、Microsoft Store、またはなし |

## ファイルの保護
- 既存のファイルを**上書きすることはありません**。足りないファイルだけを作成します。
- 自分から何かを**削除することはありません**。
- 作成したファイルはすべて `cambios.json` に記録します。
- **アプリの変更を元に戻す** は、アプリが作成し、その後誰も変更していないファイルだけをごみ箱に移動します。あなたやゲームが変更したファイルは保持されます。
- **シミュレーションモード** では、何も書き込まずに実行内容だけを表示します。

## DLL の識別
ゲームに `steam_api.dll` があるのに既知の設定ファイルがない場合、アプリは DLL を**読み取り専用で**調べます：
1. インターネットに接続せず、Windows でデジタル署名を確認します。署名が Valve のもので有効なら、そのゲームは Steam 版です。
2. ファイル内から既知のエミュレーターの特徴を探します：Goldberg、CODEX、RUNE、EMPRESS、TENOKE、OnlineFix、CreamAPI、SmartSteamEmu、3DM、ALI213、SKIDROW、RLD!、Razor1911。

結果は「詳細を表示」（ゲームを右クリック）に表示されます。

## 実績ブリッジ
実績を記録しているのに、Hydra が読まない場所に保存しているゲームがあります。**実績ブリッジ** を有効にすると、アプリは**獲得済み**の実績を Hydra が理解できる形式（`%AppData%\GSE Saves\<AppID>\achievements.json`）にコピーします。実績をでっち上げることはありません。
- **GOG Galaxy → Hydra：**実績のある GOG ゲーム向けです。Steam AppID を設定してください（右クリック →「AppID を設定」）。アプリは GOG Galaxy のデータベースの*一時コピー*を読み取り、元のファイルには触れません。API キーを入力している場合は、名前が Steam と一致する実績だけをコピーします。
- **RLE → Hydra：**Hydra は RLE のフォルダー（`%AppData%\RLE`）を知っていますがスキャンしません。ブリッジがこれを補います。
- コピー先のファイルがすでに存在し、アプリが作成したものでない場合（例：ゲームが Goldberg を使用）、**変更しません**。
- ブリッジが作成したものはすべて `cambios.json` に記録され、元に戻せます。

## 「非対応」ゲーム向けガイド
アプリは**エミュレーターをインストールしません**。こうしたゲームでは、右クリック →**「実績を追跡するためのガイド…」**で手順ガイドが開きます：
1. 現在の DLL を**バックアップ**（`.hydralogros-original` として保存。何も上書きしません）。
2. gbe_fork の公式リポジトリへのリンク。
3. DLL のフォルダーを開き、**あなた自身が**置き換えます。
4. **確認：**gbe_fork を検出すると、ゲームを自動で準備します。

DLL がすでに Valve の正規品でないコピーにのみ表示されます。

## プライバシーと Steam API の利用
- **ディスクに保存されるもの：**ライブラリ、オプション（言語を含む）、設定した AppID、作成したファイルの一覧（元に戻すため）だけです。API キーは決して保存されません。古い `config.json` にキーが含まれていた場合は、起動時に削除します。
- **ログに個人情報は残りません：**`registro.txt` と画面上では、ユーザーフォルダーは `%USERPROFILE%`、ユーザー名は `<ユーザー>` と表示され、メールアドレスとキーは隠されます。
- **アプリは Steam に慎重に問い合わせ**、キーの使われ方が普通に見えるようにします：
  - リクエストは一度に 1 件、間隔は 3 秒以上；
  - 1 セッションあたり最大 150 件；
  - 各ゲームは 1 セッションに 1 回だけ問い合わせ；
  - Steam がキーを拒否した場合、別のキーを入力するまで再使用しません；
  - Steam から頻度を下げるよう求められた場合、リクエストを 15 分間停止します。
- 実績リストは、選択した言語で Steam からダウンロードされます。

## セキュリティとスキャン
**スキャン対象：**ライブラリのサブフォルダーだけを対象に、エミュレーターやプラットフォームを識別するファイルだけを探します。音声・動画・リソース・インストーラーのフォルダーには入らず、ゲームファイルのないフォルダーは表示しません。複数のゲームを同時に確認し、ゲームごとにサイズと時間の上限があります。

**安全対策：**
- **ライブラリ：**ドライブのルート、Windows、Program Files、ProgramData、Users、プロファイル、AppData、一時フォルダーはライブラリにできません。シンボリックリンクも同様です。`config.json` に含まれていても無視されます。
- **リンク：**シンボリックリンクや *junction* はたどりません。クラウドにのみある OneDrive ファイルも読み取りません（ダウンロードを引き起こしません）。
- **書き込み：**作成できるのは `steam_settings\achievements.json`、`steam_settings\steam_appid.txt`、バックアップ `.hydralogros-original`、`GSE Saves\<AppID>\achievements.json` だけです。それ以外のパスはブロックされます。
- **元に戻す：**誰かが `cambios.json` を書き換えても、対象はこれらのファイルだけです。
- **ネットワーク：**HTTPS で `api.steampowered.com` にのみ接続し、リダイレクトには従いません。キーが別のサーバーに送られることはありません。開く Web サイトは信頼できる 2 つだけです。
- **何も実行しません：**ゲームフォルダーのプログラムを起動することはありません。フォルダーはエクスプローラーで開き、Windows の DLL は `System32` からのみ読み込みます。
- **入力データ：**AppID は数字のみ、1 MB を超えるテキストファイルは無視し、テキスト検索には時間制限があります。
- **ログ：**`registro.txt` は 2 MB でローテーションします。
- 管理者として実行すると**警告**します（その必要はありません）。

## フォルダー内のファイル
- `App\Laurel.exe`：アプリ本体。.NET 10 Desktop Runtime が必要です。
- `App\config.json`、`cambios.json`、`estado.json`、`registro.txt`：使用中にアプリが作成します。
- `leeme\`：このドキュメントの他言語版。
- `src\`：ソースコード。再ビルド：`dotnet publish src -c Release -o App`。
- `tools\IconGen\`：アイコン（`src\app.ico`）を生成します。再生成：`dotnet run --project tools/IconGen -- src/app.ico`。
- `Portable\Laurel.exe`：ポータブル版。.NET を内蔵しており（インストール不要）、データは自分のフォルダーに保存します。再ビルド：`dotnet publish src -c Release -p:Portable=true -o Portable`。
- アプリの **説明書** ボタンは、このドキュメントをあなたの言語で表示します。`.exe` に内蔵されたコピーを使うため、これらの `.md` を編集してもアプリの表示は変わりません（再ビルドが必要です）。
