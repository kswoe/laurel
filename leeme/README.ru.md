# Laurel

*Достижения — заслуженные, а не подаренные.*

**Другие языки:** [Español](../LEEME.md) · [English](README.en.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

Подготавливает ваши игры так, чтобы **Hydra Launcher записывал достижения, когда вы получаете их в игре**.
Приложение никогда не открывает достижения само.

## Как пользоваться
1. Откройте `App\Laurel.exe` и **выберите язык**. Доступно 8 языков: испанский, английский, португальский, французский, немецкий, русский, китайский и японский. Если отметить «Больше не спрашивать при запуске», язык можно сменить позже кнопкой **Язык**.
2. При первом запуске приложение само ищет папку загрузок Hydra (оно только читает данные Hydra, ничего не меняя). Если игры лежат в другом месте, нажмите **Добавить…**.
3. Введите **ключ Steam API**. Он бесплатный, получить его можно по ссылке «Получить ключ». Без ключа приложение может проверять игры, но не подготавливать их. **Ключ никогда не сохраняется:** он хранится только в памяти, поэтому его нужно вводить при каждом запуске.
4. Нажмите **Подготовить исправимые игры**.
5. Оставьте приложение открытым или сверните его (оно останется рядом с часами). Когда вы установите игру, оно дождётся конца установки и подготовит её автоматически.

**Совет:** цветные карточки над списком показывают число игр в каждом статусе; щёлкните по карточке, чтобы оставить только эти игры. Поиск фильтрует по названию, эмулятору или AppID.

## Что означает каждый статус
| Статус | Значение |
|---|---|
| OK | Hydra уже находит файл достижений этой игры |
| ГОТОВО | Всё настроено; файл появится с первым достижением |
| STEAM | `steam_api.dll` — оригинал Valve (подпись проверена): Hydra читает достижения из вашего аккаунта Steam |
| ИСПРАВИМО | Используется Goldberg, но нет списка достижений; приложение может его создать |
| НЕТ APPID | Щёлкните правой кнопкой по игре → «Указать AppID» |
| НЕ ПОДДЕРЖИВАЕТСЯ | DLL не от Valve и не содержит сигнатур известных эмуляторов: эмулятор не сохраняет достижения там, где их ищет Hydra |
| БЕЗ STEAM | Игра не использует Steam. Приложение показывает, какая платформа используется: GOG (с достижениями или без), Epic, Ubisoft, Microsoft Store или никакая |

## Как защищаются ваши файлы
- Приложение **никогда не перезаписывает** существующие файлы: оно только создаёт недостающие.
- Оно **никогда ничего не удаляет** само.
- Каждый созданный файл записывается в `cambios.json`.
- **Отменить изменения** перемещает в корзину только файлы, созданные приложением и с тех пор никем не изменённые. Если вы или игра их изменили, они сохраняются.
- **Режим симуляции** показывает, что было бы сделано, ничего не записывая.

## Определение DLL
Если у игры есть `steam_api.dll`, но нет известного файла конфигурации, приложение изучает DLL **только в режиме чтения**:
1. Проверяет цифровую подпись средствами Windows, без выхода в интернет. Если подпись принадлежит Valve и действительна, это копия из Steam.
2. Ищет в файле сигнатуры известных эмуляторов: Goldberg, CODEX, RUNE, EMPRESS, TENOKE, OnlineFix, CreamAPI, SmartSteamEmu, 3DM, ALI213, SKIDROW, RLD! и Razor1911.

Результат отображается в пункте «Подробнее» (правый щелчок по игре).

## Мосты достижений
Некоторые игры записывают достижения, но туда, где Hydra их не читает. С включёнными **мостами достижений** приложение копирует **уже полученные** достижения в формат, понятный Hydra (`%AppData%\GSE Saves\<AppID>\achievements.json`). Оно никогда не выдумывает достижения.
- **GOG Galaxy → Hydra:** для игр GOG с достижениями. Укажите их Steam AppID (правый щелчок → «Указать AppID»). Приложение читает *временную копию* базы данных GOG Galaxy, а не оригинал. Если вы ввели ключ API, копируются только достижения, названия которых совпадают со Steam.
- **RLE → Hydra:** Hydra знает папку RLE (`%AppData%\RLE`), но не проверяет её; мост это исправляет.
- Если файл назначения уже существует и создан не приложением (например, игра использует Goldberg), он **не трогается**.
- Всё, что создаёт мост, записывается в `cambios.json` и может быть отменено.

## Инструкция для НЕ ПОДДЕРЖИВАЕМЫХ игр
Приложение **не устанавливает эмуляторы**. Для таких игр правый щелчок → **«Как отслеживать достижения…»** открывает пошаговую инструкцию:
1. **Резервная копия** текущей DLL (как `.hydralogros-original`, ничего не перезаписывая).
2. Ссылка на официальный репозиторий gbe_fork.
3. Открывает папку DLL, чтобы **вы** её заменили.
4. **Проверить:** если обнаружен gbe_fork, игра подготавливается автоматически.

Предлагается только для копий, где DLL уже не оригинальная от Valve.

## Конфиденциальность и использование Steam API
- **Что сохраняется на диск:** только библиотеки, параметры (включая язык), заданные вами AppID и список созданных файлов (для отмены). Ключ API — никогда. Если старый `config.json` его содержал, приложение удаляет его при запуске.
- **В журнале нет личных данных:** в `registro.txt` и на экране папка пользователя показывается как `%USERPROFILE%`, имя пользователя — как `<пользователь>`, а адреса почты и ключ скрываются.
- **Приложение обращается к Steam осторожно**, чтобы использование ключа выглядело обычным:
  - по одному запросу, с интервалом не менее 3 секунд;
  - не более 150 запросов за сеанс;
  - каждая игра запрашивается только один раз за сеанс;
  - если Steam отклонит ключ, он не используется, пока вы не введёте другой;
  - если Steam попросит снизить частоту, запросы приостанавливаются на 15 минут.
- Список достижений загружается из Steam на выбранном языке.

## Безопасность и проверка
**Что проверяется:** только подпапки ваших библиотек, и в них только файлы, по которым определяются эмуляторы и платформы. Папки со звуком, видео, ресурсами и установщиками пропускаются, а папки без файлов игр скрываются. Несколько игр проверяются параллельно, с ограничением размера и времени на игру.

**Защита:**
- **Библиотеки:** нельзя использовать корень диска, Windows, Program Files, ProgramData, «Пользователи», папку профиля, AppData и временную папку, а также символические ссылки. Если они есть в `config.json`, они игнорируются.
- **Ссылки:** символические ссылки и *junction* никогда не открываются; файлы OneDrive, доступные только в облаке, не читаются (и не скачиваются).
- **Запись:** можно создавать только `steam_settings\achievements.json`, `steam_settings\steam_appid.txt`, копию `.hydralogros-original` и `GSE Saves\<AppID>\achievements.json`. Любой другой путь блокируется.
- **Отмена:** даже если кто-то изменит `cambios.json`, отмена затрагивает только эти файлы.
- **Сеть:** подключение только к `api.steampowered.com` по HTTPS, без перенаправлений — ключ не может попасть на другой сервер. Открываются только два доверенных сайта.
- **Ничего не запускается:** программы из папок игр никогда не запускаются. Папки открываются в Проводнике, а DLL Windows загружаются только из `System32`.
- **Входные данные:** AppID — только числа, текстовые файлы больше 1 МБ игнорируются, у текстового поиска есть ограничение по времени.
- **Журнал:** `registro.txt` обновляется при достижении 2 МБ.
- **Предупреждение**, если приложение запущено от имени администратора (это не нужно).

## Файлы в папке
- `App\Laurel.exe`: приложение. Требуется .NET 10 Desktop Runtime.
- `App\config.json`, `cambios.json`, `estado.json` и `registro.txt`: создаются приложением в процессе работы.
- `leeme\`: этот документ на других языках.
- `src\`: исходный код. Пересборка: `dotnet publish src -c Release -o App`.
- `tools\IconGen\`: создаёт значок (`src\app.ico`). Пересоздать: `dotnet run --project tools/IconGen -- src/app.ico`.
- `Portable\Laurel.exe`: портативная версия. .NET уже внутри (ничего устанавливать не нужно), данные хранятся в её собственной папке. Пересборка: `dotnet publish src -c Release -p:Portable=true -o Portable`.
- Кнопка **Справка** в приложении показывает этот документ на вашем языке. Используется копия, встроенная в `.exe`: изменение этих `.md`-файлов не меняет то, что показывает приложение (нужна пересборка).
